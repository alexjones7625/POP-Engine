## CTA-001: First-Person Pattern

### Quantified Impact
**First-person CTAs increase CTR by 20%**

### The Pattern
```
[Action Verb] + my + [Benefit/Outcome]
```

### Transformation Table
| Avoid | Use | Why Better |
|-------|-----|------------|
| Start your free trial | Start my free trial | Creates ownership |
| Get your discount | Get my discount | Mental possession |
| Sign up for updates | Send me updates | Personal agency |
| Reserve a spot | Reserve my spot | Stakes feel real |
| Download the guide | Get my free guide | Already theirs |
| Create your account | Create my account | Identity claim |

### Template Library
```
Get my [benefit]
Start my [journey/trial/subscription]
Claim my [discount/offer/spot]
Send me [content type]
Reserve my [spot/seat/access]
Show me [results/demo/options]
Give me [access/entry/the guide]
```

## CTA-002: Action Verb Library

### High-Performing Verbs
| Verb | Best For | Energy Level |
|------|----------|--------------|
| Get | Downloads, discounts | Medium |
| Start | Trials, journeys | High |
| Claim | Limited offers | High |
| Discover | Exploration | Medium |
| Join | Community, membership | Medium |
| Try | Low-risk offers | Low |
| See | Demos, previews | Low |
| Find | Search, quiz | Medium |
| Save | Discounts | Medium |
| Learn | Education | Low |
| Unlock | Exclusive access | High |
| Grab | Urgency | High |

### Verbs to Avoid
| Avoid | Why | Better Alternative |
|-------|-----|-------------------|
| Submit | Feels like compliance | Send, Complete |
| Click here | Vague, dated | [Specific action] |
| Buy now | Too pushy early | Get, Try, Start |
| Register | Corporate feel | Join, Sign up |
| Enter | Passive | Join, Get access |

## CTA-003: Benefit-Focused CTAs

### The Pattern
```
[Action] + [the benefit they get]
```

### Examples
| Generic CTA | Benefit-Focused CTA |
|-------------|---------------------|
| Download now | Get my productivity guide |
| Sign up | Start saving 10 hours/week |
| Subscribe | Get exclusive deals first |
| Learn more | See how it works |
| Buy now | Get clear skin in 30 days |
| Register | Unlock VIP pricing |

### Rule
The CTA should answer: "What do I get when I click?"

## CTA-004: Urgency CTAs

### When to Use
- Flash sales with real deadlines
- Limited inventory
- Time-sensitive offers
- Final reminders

### Patterns
```
"Claim my discount before midnight"
"Get it before it's gone"
"Reserve my spot (only 5 left)"
"Lock in my price now"
"Save my seat"
"Yes, I want in"
```

### Urgency Amplifiers
Add these around (not in) the CTA:
```
[CTA Button]
↓
"Only 3 hours left"
"12 spots remaining"
"Ends at midnight"
```

## CTA-005: Low-Friction CTAs

### When to Use
- Cold audiences
- High-ticket items (early funnel)
- Skeptical segments
- Complex products

### Patterns
```
"See how it works"
"Take the quiz"
"Show me examples"
"Learn more"
"Watch the demo"
"Browse options"
"Compare plans"
```

### Friction Spectrum
```
Lowest → Highest Friction:

See → Learn → Try → Start → Get → Claim → Buy
```

## CTA-006: Placement Strategy

### Email Placement Rules
| Position | Purpose |
|----------|---------|
| Above the fold | Catch impulse clickers |
| After value proposition | Logical decision point |
| End of email | For readers who consume everything |

### Optimal Pattern
```
[Subject line]
[Opening hook - 2-3 sentences]
[CTA #1]
[Body content - main value]
[CTA #2]
[Closing/PS]
[CTA #3 - can be text link]
```

### Rule
Same action, 2-3 placements. Never different CTAs competing.

## CTA-007: Button Design Rules

### Quantified Stats
| Element | Impact |
|---------|--------|
| Red button vs green | 21% higher conversion |
| High contrast vs blend | Significant lift |
| Rounded corners | More clicks than sharp |

### Size Requirements
- Minimum 44px height (mobile tap target)
- Full width on mobile
- Prominent but not overwhelming on desktop

### Visual Hierarchy
```
1. Button should be the most visually prominent element
2. Sufficient whitespace around button
3. Contrasting color from background
4. Clear, readable text
```

## CTA-008: Button vs Text Link

### When to Use Each
| Button | Text Link |
|--------|-----------|
| Primary CTA | Secondary mention |
| Above the fold | PS line |
| Mobile-first design | Long-form content |
| Promotional emails | Text-based emails |
| High-intent actions | Soft nudges |

### Hybrid Approach
```
[BUTTON: Primary CTA]

or [text link: same CTA for those who prefer links]
```

## CTA-009: Mobile CTA Rules

### Requirements
- Minimum 44x44px tap target
- Full-width buttons on mobile
- Thumb-friendly placement (bottom 2/3 of screen)
- Sufficient padding around buttons
- Stack buttons vertically, never horizontally

### Testing
Always preview on actual mobile device before sending.

## CTA-010: Email CTA Frequency

### Rule
**2-3 CTA placements per email, all pointing to same action**

### Distribution
| Email Length | CTA Count |
|--------------|-----------|
| Short (under 100 words) | 1-2 |
| Medium (100-200 words) | 2 |
| Long (200+ words) | 2-3 |

### Anti-Pattern
Never have multiple different CTAs competing:
```
BAD:
[Buy Product A]
[Learn About Service B]
[Sign Up for Newsletter]

GOOD:
[Get My Discount] ← same action
[Shop Now] ← same action, different words
```

## CTA-011: Landing Page CTAs

### Placement Pattern
```
Hero section → CTA #1
After problem/solution → CTA #2
After social proof → CTA #3
Bottom of page → CTA #4 (final)
```

### Sticky CTA
For long pages, use sticky button that follows scroll.

### Above vs Below Fold
- Above fold: Higher conversion for impulse
- Below fold: Higher quality leads (they read first)
- Best: Both

## CTA-012: CTA Anti-Patterns

### Never Do
| Anti-Pattern | Why It Fails |
|--------------|--------------|
| "Click here" | Vague, no value proposition |
| "Submit" | Feels like compliance |
| Multiple competing CTAs | Splits attention, reduces conversion |
| CTA buried in text | Easy to miss |
| Generic "Learn more" everywhere | No urgency or specificity |
| ALL CAPS CTA | Feels aggressive |
| Tiny, hard to click buttons | Mobile friction |
| Same color as background | Invisible |

### Test Yourself
Before finalizing CTA, ask:
1. Does it create ownership? (first-person)
2. Does it promise a benefit?
3. Is it visually prominent?
4. Could someone understand what happens next?

## CTA-013: Benefit-Based CTA Copy

**Source**: email_anatomy.md

### The Pattern
Replace generic CTAs (Shop Now, Buy Now) with benefit-driven or action-based phrases.

### Why It Works
Benefit CTAs reinforce the value proposition at the moment of decision. They're more memorable and compelling than generic actions.

### Application
Ask "What will the customer become/achieve?" and use that as CTA text.

### Examples
| Generic CTA | Benefit-Based CTA |
|-------------|-------------------|
| Shop Now | Be Extraordinary |
| Buy Now | Try Granola |
| Order | Crack a Can |
| Learn More | Start Here |
| Shop Collection | Wake Up Energized |

## CTA-014: Button Size Principle

**Source**: max_video_transcript.md

### The Rule
Bigger buttons = more clicks. Don't use small, subtle buttons.

### Why It Works
Visibility drives action. People can't click what they can't easily see and identify as clickable. Subtle design loses to obvious design.

### Application
- Make buttons prominent, large, high contrast
- Don't sacrifice visibility for "clean" design
- Thumb-friendly on mobile (44px minimum)
- Full-width buttons on mobile often outperform

### Size Hierarchy
```
BEST: Large, full-width, high contrast
GOOD: Medium, centered, contrast color
BAD: Small, subtle, blends with design
```

## CTA-015: Countdown Timer in Last Chance Emails

**Source**: max_video_transcript.md

### The Rule
Add dynamic countdown timer in final urgency emails showing time until discount expires.

### Why It Works
Visual urgency is more compelling than text urgency. Creates anxiety about missing out that text alone cannot achieve.

### Application
- Use Klaviyo countdown timer block or design one in Figma
- Place prominently near CTA
- Only use when deadline is real

### Structure
```
[Headline: Last Chance]
[Countdown Timer: 02:45:30 remaining]
[CTA Button]
```

### When to Use
- Final email in abandonment flow
- Last day of sale
- Discount expiration reminder
- Limited inventory alerts
